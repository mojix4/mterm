# MTerm

ترمینال SSH سبک و سریع برای اندروید، شبیه Termius.

- ذخیره سرورها با رمز یا کلید SSH (رمزنگاری‌شده روی گوشی)
- ترمینال کامل xterm-256color با نوار کلید (esc, ctrl, alt, tab, فلش‌ها، …) قابل شخصی‌سازی
- چند نشست هم‌زمان، تأیید کلید سرور (known hosts)
- دستورهای ذخیره‌شده، تاریخچه و پیشنهاد خودکار
- ۶ رنگ‌بندی، زوم با دو انگشت، روشن ماندن صفحه، keep-alive
- قفل برنامه با PIN و اثر انگشت
